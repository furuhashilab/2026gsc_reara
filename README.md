# ゼミ論構想

## レンタルボート初心者向け航行情報WebGISの開発（仮）

**レンタルボート初心者に必要な情報の整理とWebGISによる可視化に関する研究**

---

# Introduction(導入)


小型船舶免許取得後に初めてレンタルボートを操船した際、インストラクターが同乗していたため安心して航行できたものの、一人であればどの航行ルートを選択すべきか判断できないと感じた。また、一緒に講習を受けた受講者からも、「誤って狭い水路に入ってしまい、操船しづらかった」という経験を聞いた。さらに、地域ごとのローカルルールや航行時の注意事項が存在することも知り、初心者が事前に把握すべき情報は多いと感じた。

そこで本研究では、**レンタルボート初心者が出港前に必要とする情報を整理し、それらをWebGISで可視化する方法を検討すること**を目的とする。

---

# Methods（研究方法）

## 対象地域

神奈川県横浜市のみなとみらい周辺を出港地点とする横浜港内を対象地域とする。
横浜港内には、大型船が航行する海域、運河、狭い水路、航行管制に関する情報など、初心者が事前に確認すべき多様な航行環境が存在する。

## 必要情報の整理

レンタルボート初心者が出港前に必要となる情報を整理する。

* レンタルボート施設
* 出港場所・港
* 利用ルール
* ローカルルール
* 航行管制情報
* 注意すべき航行環境（狭い水路、大型船の航路など）
* 駐車場
* トイレ
* コンビニ
* 給油施設
* ライフジャケット貸出


## 情報収集

* 自治体、海上保安庁、レンタルボート事業者、港湾管理者などの公開情報を収集する。
* 横浜港周辺のマリーナやレンタルボート施設を訪問し、初心者向けに提供されている案内や注意事項を調査する。

## WebGISの作成

収集した情報を整理し、初心者向けWebGISとして可視化する。

---

# Results（想定される結果）

* レンタルボート初心者に必要な情報を分類・整理できた。
* 必要な情報が複数の情報源に分散していることを整理できた。
* 初心者が出港前に確認すべき情報を一元的に閲覧できるWebGISを試作できた。

---

# Discussion（考察）

* レンタルボート初心者にとって特に重要な情報は何か。
* 現在の情報提供にはどのような課題があるか。
* WebGISによる情報の一元化は、初心者の事前準備にどのように役立つ可能性があるか。
* 今後、より実用的なWebGISとするために必要な情報や機能について検討する。
